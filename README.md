# ContactTrace Robotics

ContactTrace Robotics is an independent robotics research initiative focused on simulation, automated testing, robot-policy evaluation, failure analysis, real-to-simulation workflows, and sim-to-real validation.

## Real2Isaac

Real2Isaac is an active research prototype that transforms captured real-world environments into robot simulation scenes.

The current pipeline includes:

- Real-world video capture
- COLMAP-based camera reconstruction
- Gaussian Splatting for 3D scene generation
- USD conversion and NVIDIA Isaac Sim integration
- Ground and obstacle collider generation
- Mobile robot integration for navigation testing

▶️ [Watch the Real2Isaac demo](https://contacttrace-robotics.github.io/#projects)

## ContactTrace Sim

ContactTrace Sim is the broader platform vision:

**Capture → Build → Evaluate → Validate**

The goal is to connect real-world scene capture, robot integration, simulation-based policy evaluation, failure analysis, and deployment validation through a common workflow.

## Research Areas

- Robot simulation and digital twins
- Automated robot-policy evaluation
- Failure classification and targeted testing
- Real2Sim and sim-to-real workflows
- ROS 2 and robot integration
- MuJoCo and NVIDIA Isaac Sim
